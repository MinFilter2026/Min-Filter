MIN FILTER

নিরাপদ ইন্টারনেট, সুন্দর ভবিষ্যৎ

Android-এর জন্য VPN-ভিত্তিক domain/DNS filtering MVP। এক ট্যাপে protection চালু করা, নির্বাচিত domain block করা, trusted domain whitelist এবং custom blocklist—সব এক জায়গায়।

GitHub Documentation

Web / DNS

Domain-based rules এবং family-friendly upstream DNS ব্যবহার করে filtering।

Short-video

TikTok, Likee, SnackVideo ও Kwai-এর নির্বাচিত domain block করা যায়।

Whitelist

Trusted domain list থাকলে সেটি reject rules-এর আগে DIRECT হিসেবে প্রয়োগ হয়।

Custom blocklist

নিজের domain list যোগ করে protection চালু অবস্থায় rules restart করা যায়।

গুরুত্বপূর্ণ সীমাবদ্ধতা

  • এটি content classifier বা antivirus নয়।
  • Direct-IP traffic এবং domain signal না পাওয়া encrypted traffic সবসময় domain দিয়ে চেনা সম্ভব নয়।
  • YouTube Shorts / Instagram Reels-কে parent domain-এর HTTPS traffic থেকে নির্ভরযোগ্যভাবে আলাদা করা যায় না; তাই পুরো domain block option দেওয়া হয়েছে।
  • বাস্তব Android device, Wi-Fi/mobile-data এবং OEM-specific behaviour পরীক্ষা ছাড়া production release দাবি করা যাবে না।
